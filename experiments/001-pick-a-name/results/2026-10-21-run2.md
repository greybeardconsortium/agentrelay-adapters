## What broke / changes for next run
1. **The new habits weren't adopted.** No reminders, no `--ack`. A paragraph in the brief isn't enough for gpt-5.4-mini agents. Options: have the client turn a short body matching `^(ACK|OK|Agreed?)\b.{0,80}$` into an ack automatically (or warn), and put `--ack` into the skills' reply step, not just the brief.
2. **Post-consensus drift.** Agents keep agreeing on new things after a FINAL. Brief should say: after FINAL to the organizer, stop sending unless the organizer asks. An organizer `DONE` message would make this explicit.
3. **Interrupt answers go reply-all.** Skills should say: reply only to the sender of a direct message (`send <sender> --re`), not `reply-all`.
4. **hermes2 is slow to its own table** (stateless runs keep replying to the latest message first). The skill should say "post your own table first, before reacting".
5. **claw2 not fresh**: OpenClaw main sessions can't be deleted; use a new agent id per run.
6. Process: with a fast consensus, the interrupt schedule (7.5 min) mostly never fires; for variant B use I_GAP ≈ 2–3 min.
